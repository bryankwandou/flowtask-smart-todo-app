# FlowTask

> Turn your daily chaos into focused progress. — [Live Demo](#)

## Problem

Most to-do list applications only allow users to list tasks. They do not help users:
- Stay focused
- Understand productivity patterns
- Maintain consistent daily progress

As a result, users accumulate unfinished tasks and lose motivation.

## Solution

FlowTask introduces:
- Smart task management
- Focus mode timer
- Productivity analytics
- Completion streak tracking
- Intelligent reminders

## Why

FlowTask is not just a task list — it is a personal productivity intelligence tool. The application analyzes task completion behavior and provides insights into productive hours, completion streaks, and task consistency.

## Architecture

Architecture Model: Mobile Client -> 100% Offline Local Storage

Components:
- Flutter App
- SQLite / Shared Preferences Local Storage
- Local Notification System

## What's Built

- Offline Smart Task Management
- Productivity Analytics Dashboard
- Reminders System
- Fully Native Feel with Custom UI/UX
